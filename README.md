# UpNorth Gaming

The website for UpNorth Gaming, a two-person independent game studio: [upnorthgaming.com](https://upnorthgaming.com).

It's a static [Jekyll](https://jekyllrb.com) site that GitHub Pages builds from `main`, so pushing publishes it. Devlog updates are Markdown files in `_posts/`, and released games are Markdown files in `_games/`.

- [`DEVELOPMENT.md`](DEVELOPMENT.md): running the site locally, posting updates, adding games, and hosting setup.
- [`AGENTS.md`](AGENTS.md): how the site is put together, for contributors and AI coding agents.
